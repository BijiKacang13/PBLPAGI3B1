Tentang Aplikasi

Platform digital untuk pengelolaan keuangan seluruh unit pendidikan di bawah Yayasan Darussalam Batam. Mendukung pencatatan transaksi, pelaporan keuangan, dan penyusunan RAPBS secara terpusat.

Fitur Utama

  • Pencatatan transaksi pemasukan & pengeluaran
  • Laporan keuangan otomatis
  • Penyusunan dan monitoring RAPBS
  • Manajemen akun dan pengguna
  • Audit trail aktivitas sistem
  • Dashboard real-time

Mode Offline

Saat tidak ada koneksi internet, akses ke data server tidak tersedia. Pastikan perangkat terhubung ke jaringan untuk menggunakan seluruh fitur aplikasi. Tekan tombol di bawah untuk mencoba menyambung kembali.
